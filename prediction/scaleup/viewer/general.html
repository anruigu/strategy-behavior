What each representation contains

Structured: family, objective, action format, public parameters, player identity, seat and prompt label.

Full: structured plus exact initial player messages and an opponent-policy description. These messages can include the focal player’s own private opening information.

Engine facts: full plus documented parser, payoff and numerical opponent details. Extra facts go to the predictor only. Hidden opponent state and future draws are never supplied.

The learned baselines use training-only structured features and, for full inputs, TF–IDF text features. Logistic/Ridge and a small MLP use fixed regularization; this is a diagnostic comparison, not a tuned large-data benchmark.
