# Approved v3-MA four-model screen

Run started 2026-09-09 after a 16/16 successful interface pilot.

- Models: Claude Haiku 4.5 and GPT-5 mini through OpenRouter; Qwen 3.8 27B and GLM 5.3 through FLT.
- Main design: 768 episodes, 16 ordered model pairs including self-play, seeds 0 and 1.
- Ten recipient-dependent scenarios: ordinary and privately nerfed recipients. Four commons scenarios: ordinary only.
- All episodes use the open referee arm. Three-seat scenarios use the opponent model for both non-focal seats, with separate contexts.
- No training or across-episode memory. Scores and trace predicates describe play, not learned policies.
- One public-schema correction is allowed after a malformed submission; all rejected replies remain recorded. At most two transport/completion attempts per submission, with 8,192 then 16,384 output tokens.
- A separate $200 OpenRouter accounting ceiling applies. FLT dollar charges are not supplied by the transport. Reservations for in-flight requests are not actual spend.

`plan.json` and `source/` freeze the execution settings, definitions, and implementation. `status.json` records progress and API accounting. `report.json` and `REPORT.md` are generated by the campaign after it finishes, or can be refreshed while it runs:

```bash
/shared/allie/venvs/hole/bin/python -m benchmark.v3_ma.report --out benchmark/results/v3-ma-four-model-20260909
/shared/allie/venvs/hole/bin/python -m benchmark.v3_ma.plot --out benchmark/results/v3-ma-four-model-20260909
```

The pilot directories are separate from the main sample. The first pilot finished 15/16; one Haiku response included an extra later-stage action. After introducing the explicit current-stage instruction and one neutral correction, the second pilot finished 16/16. Pilot outcomes are not pooled with main outcomes.

Failures must remain visible. Matched payoff differences use only pairs where both ordinary and nerfed episodes completed. A structural marker may be absent because no attempt occurred or because a recipient did not respond; inspect the round-level evidence before interpreting it. Message-response associations and convention consistency are particularly limited indicators and cannot alone establish causality or intent.
