# v3-MA reflection comparison

Four scenarios: Council, account reset, clue convention, and pledge. All four focal models and all four opponent models form 16 ordered pairings. Both ordinary and privately nerfed opponent conditions are included.

Each of 128 game/lineup/condition chains reuses its original completed seed-0 first play. Two continuations branch from exactly that same experience: transcript only and transcript plus private reflection. Each branch makes three new plays. Plays 2–3 reuse seed 0; play 4 uses seed 1. Only the clue convention has seed-dependent target draws in this subset; the three trust-family games have deterministic initial states, so play 4 remains a repetition for them. Total: 128 shared baselines and 768 new episodes, with up to 384 reflection calls.

Only the focal retains its own complete observations and replies, including neutral format corrections and a final seat-visible observation of the last outcome. Reflection sees the same history, not the research answer key, exploit labels, hidden state, future draws, or other players’ private prompts. Both arms have the same repeated-play instruction. Opponents start with fresh contexts each play while their identities, seat positions, and private policy treatments stay fixed. No weights are trained.

The initial interface pilot comprises play 2 of 16 preselected nerfed Council/convention self-play branches. Those checkpoints remain part of the main experiment if the protocol is unchanged. Completed game responses and reflection notes are never resampled: resume verifies every exact request hash. One recovery pass is allowed after main execution.

The four model configurations match the original screen, including provider-default temperature and low requested reasoning effort. Each request has an 8,192-token allowance and at most one retry with 16,384 tokens. One neutral action-schema correction is allowed. Full contexts have a 300k-byte bound and are never silently truncated. The separate $200 accounting ceiling applies to OpenRouter; FLT dollar charges are unavailable. Temporary in-flight reservations can delay requests, and are not reported spend.

Primary comparisons pair the two memory arms by initial episode and play number. Failed or missing episodes do not become misses. Marker definitions are frozen from the original screen. Council also gets a separate recipient-choice audit, requiring an open trading pair for the profitable request/betrayal count. The final seed switch tests limited instance transfer; it does not establish generalization over many random seeds. Reflection includes extra inference compute and a structured review prompt, so this is not a compute-matched comparison.

Execution settings, baseline hashes and source snapshots are frozen in `plan.json` and `source/`. Raw requests, replies and costs are retained alongside each episode or reflection. `REPORT.md` and `report.json` contain the paired results; reflection plots are generated from them.

Transport amendment, recorded before recovery: the main runner used a 180-second request timeout, while the base client uses 600 seconds. Successful GLM private notes had a median duration near 150 seconds, with many requests timing out. The single recovery pass restores 600 seconds for all models and retains 24 workers. Model request bodies, prompts, token limits, retry count, budget ceiling, and all accepted replies remain unchanged. The frozen plan and original sources are preserved; `transport-amendment.json` records the additional adapter source and its hash. `status.main.json` and `report.main.json` preserve the main pass separately.
