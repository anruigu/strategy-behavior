# The variant catalogue AS MEASURED ON 2026-09-02, before the SIZE axis was retired

These two files are the audit exactly as it stood when it was run: 89 variants
over 34 cells, including the 21 `SIZE` branches.

THE SIZE AXIS WAS RETIRED ON 2026-09-03. It moved how much the exploit pays
without changing the direction of anything -- a bigger number in the same
regime -- so every question it could answer was a question about amplitude in
an analysis whose subject is direction. `variants.py`, `configs/` and
`variant_audit.py` no longer carry it. This snapshot is kept because the
measurements are real and were paid for, and because `CATALOGUE.md` is cited
by `research_logs/0902-branch-variations.md` and by
`research_logs/0903-payoff-wave1-draft.md`, both of which quote SIZE rows.

Nothing reads this directory. The live catalogue is one level up.
