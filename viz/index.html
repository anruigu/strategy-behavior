Exploit-bench — run groups

Five groups of runs, each answering a different question. This page is triage, not results: it shows how much evidence is in each bundle and whether any of it is in a state where the headline should not be read. The numbers behind each are one click away — deliberately, because a single figure per bundle, stripped of the arm structure that gives it meaning, is the bare scalar the benchmark's own reporting rules refuse.

OK nothing blocking.   WARN read the caveat before quoting a number.   STOP the headline is not readable as stated — usually because the instrument measured something other than what it claims. Every count is derived from the bundle on disk by build_index.py, so a group that says six targets is saying what the builder actually wrote.
