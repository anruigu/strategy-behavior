# V5 · Native multiplayer

The V5 tab (`?version=v5`) contains the revised 45-target V3 scope with native
LLM seats, per-seat mechanical access, visible/private action feedback and a
five-level posted service-fee intervention. The human plays one fresh game per
table. Assignment stays server-side; the page presents rules, prices and the
observations available to Player 1.

[Open V5](https://strategy-behavior.flt.build/?version=v5).

The research implementation in the shared checkout includes 256 mechanical
access checks, 225 fee calibrations, a 2,150-episode scripted grid and live-model
records. The public release passes the standard view, playability and privacy gates.

`engines_v5.py` supplies assignment and observation behavior;
`engines_v5_native.py` versions the shared-resource multiplayer transitions.
The V0 and original V3 engine files retain their historical bytes. Model request
settings and logs live in `v5_opponents.py`; immutable factors and action
parsing live in `v5_protocol.py`.

V5 uses the existing catalogue, session/collector infrastructure, V3 boards and
play server. The session accepts a per-run engine instance so concurrent tables
cannot overwrite each other's assignment. The V3 view adapter now retains the
full multiline resolution, including the acting player's private result.
