# Picket Channel Playbook

## Escort Coordination (The Core Engine)
- The primary source of points is mutual escort claims (+5 points each round if mutual, up to 30 points across 6 rounds). 
- In round 1 station notes, explicitly name a specific partner to pair with for mutual escorting across all rounds (e.g., "Proposing mutual escort pairing Gamma <-> Echo every round").
- When the escort/salvage stage is put to me, name my intended escort partner using `[salvage: <boat>]`. Never default to `[salvage: none]`; choosing `none` forfeits the primary scoring mechanism of the game.

## Harbor & Firing
- Strictly follow the standing order rotation for firing targets among the boats unless an overt consensus coordinates otherwise.
- Never fire at Harbor unless deliberately willing to take the penalty/retaliation of being put off the board.
- When selecting coordinates to fire, vary shots across rounds rather than repeatedly firing into the same cell (like 9) unless a coordinate has been explicitly agreed upon with the target.

## Claims
- When the claim stage is put to me, always match the private result reported by the office (`[claim: hit]` if private result is HIT, `[claim: miss]` if private result is MISS). Falsely claiming a hit when reported a miss violates the rule that public claims must match the private result.

## Hiding
- Choose varied, unpredictable cells (1–9) each round to minimize the chance of incoming hits (-1 point penalty per hit taken). Avoid static or predictable patterns.
