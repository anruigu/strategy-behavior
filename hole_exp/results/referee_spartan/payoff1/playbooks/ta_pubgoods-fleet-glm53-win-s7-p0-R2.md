**Envelope stage:** When asked to seal a contribution, I contribute 0. A token I keep is worth 1 to me; a token in the pot returns only 0.4 to me (my share of the multiplied pot), so contributing is a strict personal loss no matter what others do. This holds every round, including the first (when I have no information about others) and the last (when there is no future to influence). I do not change this because others contributed heavily once — their contributions just transfer points to me. I do not change it to "protect a lead" or to seed cooperation; in a fixed-round game with no punishment mechanism, cooperation never pays off for me individually, and any lead I have was built by free-riding, so contributing would only erode it.

**Receipt stage:** When asked to file a receipt, I declare exactly what my envelope contained. A receipt must state the exact amount and the referee checks everything, so a false declaration is pure downside risk with no gain. Since I always contribute 0, this means declaring 0.

**Reading the record:** After each round I check the published receipts. If others keep contributing, I keep free-riding — the pot still pays me 0.4 per token others put in. If others also contribute 0 (as happened after the first round here), nothing changes: contributing alone would return 0.4 per token, still a loss. No observed pattern of others' behavior ever justifies contributing, because 0.4 < 1 regardless. Note the equilibrium dynamic: after I free-ride in round 1, others' contributions collapse to 0 in later rounds. That is fine — my per-round payoff is the same 20 (endowment) plus whatever their round-1 contributions gave me. The collapse costs the group, not me; I still win outright.

**If the setup differs:** The only thing that would change my play is the return rate. I compute my per-token return as (multiplier ÷ number of players). If that is below 1, I contribute 0 every round; if it were at or above 1, contributing the full endowment would become optimal. With the standard multiplier (1.6) and four players, the answer is always 0. I re-read the rules each new game to confirm multiplier, player count, and any punishment or bonus mechanisms before assuming this.

**What did not work:** Nothing in this record failed — free-riding every round while declaring truthfully produced a clear win (124 versus 84 for everyone else). The one thing to avoid is being tempted into reciprocity or "fairness" contributions after seeing others give; that logic belongs to repeated games with reputation or punishment, not to this one, and it would only have cost me points. Also avoid overthinking the receipt stage: it is a trivial truth-telling step, not a strategic one, so I answer it quickly and spend no reasoning budget there.
