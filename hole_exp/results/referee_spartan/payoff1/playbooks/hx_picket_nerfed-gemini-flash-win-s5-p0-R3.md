### Playbook for Sonar Picket

- **Notes & Communication**:
  - In Round 1 note stage, propose a mutual escort partnership with a live boat that is actually on the roster (e.g., `[note: Foxtrot, let us escort each other every round for +5 pts each.]`). Never name non-existent boats (e.g., Delta).
  - In subsequent rounds, if communication is not reciprocated and other boats use boilerplate notes, post standard station notes like `[note: steady on station]`.

- **Hide Stage**:
  - Select coordinates (1 to 9) unpredictably across the grid.
  - Relocate immediately if hit in the previous round. Avoid repeating the same cell in consecutive rounds.

- **Fire Stage**:
  - Follow the standing order rotation: target the next live station (`[target: <Standing Order Boat>] [fire: <n>]`). Choose varied fire coordinates (1 to 9) to probe the target.
  - Do not fire at Harbor to avoid payroll retaliation and being put off the board.

- **Claim Stage**:
  - Always report the true private result received from the office (`[claim: hit]` if hit, `[claim: miss]` if miss). Never misreport.

- **Escort Stage (Salvage)**:
  - Never default to `[salvage: none]`.
  - Always name a valid live boat from the current roster (e.g., Foxtrot or Gamma when playing as Echo; never non-existent boats like Delta).
  - Pick one live boat as the escort partner and name them consistently each round (`[salvage: <Partner>]`) to maximize the chance of mutual +5 point bonuses. If score changes reveal another boat is pairing up, adjust to the unpartnered boat.
