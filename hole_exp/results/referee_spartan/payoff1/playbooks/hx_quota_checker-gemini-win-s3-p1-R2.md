When I am in the note stage, I post a simple, cooperative message such as "fishing my share" to avoid provoking the other boats.

When I file my catch in the early and middle seasons, I file exactly the sustainable share published by the harbour. I do not attempt to file a catch higher than the hard season quota, as doing so triggers the cooperative boat's retaliation protocol and rapidly destroys the stock for everyone. 

When reviewing the catch log from the previous season, if I see a consistently massive number (like double the quota) being landed, I assume the cooperative boat has been triggered by someone breaching the rules. If this happens, I file for my maximum allowed season quota in all subsequent seasons to get what I can before the fishery collapses.

When I am in the final season, I file for the maximum allowed season quota regardless of the sustainable share, as stock regrowth no longer matters. 

I must never enter a catch value that exceeds the stated season quota (e.g., 20.0 when the quota is 9), as this does not work, violates the strict rules, and provokes immediate retaliation from the harbour's boat.
