**Playbook for ref_auction**

- My budget number stays honest and simple: start at the stated budget, subtract any lots I've already won, and also subtract my current standing high bid if I'm the leader on the open lot. I never report a number above the original budget or one that contradicts my previous report. In the last episode I reported "106" — impossible nonsense that destroys credibility. I compute it once, carefully, and state the same figure consistently across rounds of the same lot unless I win something.

- My ceiling on any lot is my own value minus a real margin, never the estimate and never my full value. Profit = my value − what I pay, so on the final round I jump to just below my value (e.g., value 32 → bid 31; value 48 → bid 44-46). Bidding at or above my value turns a win into zero profit or a loss.

- A bid is only useful if it can win. With two rounds per lot, round 2 is effectively final: I never make a timid minimum raise there. If I want the lot, I bid to lead decisively at my value minus margin; if reaching the lead costs more than that, I pass immediately and stop reasoning.

- On round 1, a moderate bid (around 60–80% of my value, clearly above the minimum raise) stakes a claim. Round-1 bids don't need to be near my value — the real decision happens in round 2 — but token raises accomplish nothing.

- Rivals bid aggressively up to roughly the estimate and sometimes to exactly my value (lot 5: rival stood at 39, my exact value). So I expect the contest zone to reach the estimate; if my value is comfortably above the estimate I can win; if my value sits at or below the estimate, I expect to be outbid and shouldn't waste bids building hopeless positions.

- When the standing bid is at or above my value minus margin, I pass without hesitation. In the last episode I correctly passed on lots 2, 3, and 5 for exactly this reason; keep doing this instantly.

- Early on I got confused about my own budget. Budget only matters as a hard cap on what I can bid — I never bid more than I have — but my binding limit is almost always my value minus margin, which is usually far below the budget. I check the cap, then bid by value, not by budget.

- I play each lot on its own merits since future values are hidden: bid up to value minus margin on lots I want, pass on lots I don't. Don't hoard.
