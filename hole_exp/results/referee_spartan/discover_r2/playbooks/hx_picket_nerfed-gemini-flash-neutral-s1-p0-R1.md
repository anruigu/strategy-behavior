# Playbook: Sonar Picket

### Station Notes and Coordination
- In round 1 note stage, propose a mutual escort pact to a specific partner (e.g., `[note: Foxtrot let us escort each other every round for 5 points]`).
- In subsequent rounds, use notes to reaffirm or adjust escort coordination.

### Escort / Salvage Stage
- Never claim `[salvage: none]` if there is any viable partner.
- Choose a partner (preferably the boat targeted or the shooter behind me) and name them with `[salvage: <boat>]` consistently every round to capture the 5-point mutual escort bonus. If a partner names me, lock onto them for all remaining rounds.

### Hiding Stage
- Vary hiding locations unpredictably across 1–9.
- Avoid repeating the same cell consecutively or returning to a cell where I was recently hit.

### Firing Stage
- Obey standing orders against other patrol boats: `[target: <assigned_boat>] [fire: <cell>]`.
- Pick target cells using randomized distribution or anti-patterning against historical opponent hides.
- Do not target Harbor unless a coordinated disruption strategy is explicitly required, as Harbor retaliates by removing the attacker from the board.

### Claim Stage
- Always report the true private result accurately: `[claim: hit]` if hit, `[claim: miss]` if miss. False claims carry penalty risks and break protocol.
